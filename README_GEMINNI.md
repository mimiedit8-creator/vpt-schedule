Telegram-бот расписания ВПТ — РКЛ-3

Telegram-бот-помощник для студентов ГБПОУ «Волжский политехнический техникум» (корпус №2, группа РКЛ-3).

Бот получает расписание из официального облака техникума, отправляет его в Telegram и объединяет дополнительные функции: ИИ-ассистент Google Gemini, отслеживание посылок Яндекс Доставки, музыку, избранное, домашние задания, новости и статистику.

Возможности

 ● Расписание: на сегодня, завтра и неделю; данные берутся из Nextcloud техникума.
 ● Автоотправка: расписание на завтра отправляется по расписанию, а бот также проверяет появление нового файла.
 ● ИИ-ассистент Gemini: включается командой /ai или кнопкой 🤖 ИИ-ассистент. Пока режим активен, обычные сообщения отправляются Gemini.
 ● Выход из ИИ: кнопка ❌ Отмена или команда /cancel выключает режим ИИ и возвращает главное меню.
 ● История ИИ: контекст диалога сохраняется в state.json; его можно очистить кнопкой 🧹 Очистить историю. Доступен выбор модели через 🔄 Сменить модель.
 ● Посылки: отслеживание посылок Яндекс Доставки; сохранённые номера можно использовать повторно. Проверка выполняется периодически.
 ● Музыка: подборки из плейлиста «Мне нравится» Яндекс Музыки, поиск, избранное и ссылки на прослушивание.
 ● Домашние задания: добавление, просмотр и удаление записанных заданий.
 ● Новости, настройки и статистика доступны через главное меню.

Файлы проекта

Основной файл бота:

vpt_bot_gemini_toggle.py

Также бот использует файлы состояния и кеша, которые создаются по мере работы:

 ● state.json — настройки чатов, история Gemini, статистика, отслеживаемые посылки и другие данные;
 ● music_cache.json — кеш музыкального плейлиста (если используется в текущей конфигурации).

Не удаляйте state.json, если хотите сохранить историю ИИ и данные бота.

Как пользоваться Gemini

 1. Установите и настройте бота по инструкции ниже.
 2. Добавьте секрет GEMINI_API_KEY в окружение, в котором запускается бот.
 3. В Telegram отправьте /ai или нажмите 🤖 ИИ-ассистент.
 4. Пишите вопросы обычными сообщениями — бот передаст их Gemini.
 5. Чтобы закончить диалог с ИИ и вернуться к обычному меню, нажмите ❌ Отмена или отправьте /cancel.

В режиме Gemini сообщения обрабатываются ИИ, пока вы не нажмёте отмену.История диалога хранится отдельно и не удаляется при выходе из режима. Для очистки используйте 🧹 Очистить историю.

Получение ключа Gemini

 1. Откройте Google AI Studio.
 2. Создайте API key для Gemini.
 3. Скопируйте ключ и добавьте его в переменные окружения под именем GEMINI_API_KEY.

Не вставляйте API-ключ в исходный код, README, публичные сообщения или GitHub-коммиты. Храните его только в Secrets или в защищённом окружении.

Настройка Telegram-бота

1. Создать бота

 1. Откройте @BotFather в Telegram.
 2. Отправьте /newbot.
 3. Укажите имя и username бота (username должен заканчиваться на bot).
 4. Сохраните выданный токен. Это значение TG_TOKEN.
 5. Найдите созданного бота в Telegram и нажмите Start.

2. Узнать Telegram ID

 1. Откройте @userinfobot.
 2. Отправьте ему сообщение.
 3. Сохраните числовой ID. Это значение TG_CHAT_ID.

3. Добавить секреты в GitHub

Если бот запускается через GitHub Actions:

 1. Откройте репозиторий на GitHub.
 2. Перейдите в Settings → Secrets and variables → Actions.
 3. Нажмите New repository secret и добавьте:

|Имя секрета     |Значение                                     |
|-—————|———————————————|
|`TG_TOKEN`      |Токен, полученный у BotFather                |
|`TG_CHAT_ID`    |Ваш числовой Telegram ID                     |
|`TG_PASSWORD`   |Необязательный пароль для новых пользователей|
|`GEMINI_API_KEY`|API-ключ Google Gemini                       |

TG_PASSWORD можно не задавать. Если пароль задан, новые пользователи должны пройти проверку доступа. Владелец, указанный через TG_CHAT_ID, проходит без ввода пароля.

Важно: одного добавления GEMINI_API_KEY в Secrets недостаточно. Workflow должен передавать секрет в окружение процесса как переменную GEMINI_API_KEY. Аналогично должны передаваться TG_TOKEN, TG_CHAT_ID и при необходимости TG_PASSWORD.

Пример фрагмента шага GitHub Actions:

env:

  TG_TOKEN: ${{ secrets.TG_TOKEN }}

  TG_CHAT_ID: ${{ secrets.TG_CHAT_ID }}

  TG_PASSWORD: ${{ secrets.TG_PASSWORD }}

  GEMINI_API_KEY: ${{ secrets.GEMINI_API_KEY }}

Добавьте env именно в тот шаг, который запускает Python-бота.

4. Загрузить файлы

Загрузите в репозиторий:

 ● vpt_bot_gemini_toggle.py;
 ● папку .github с workflow-файлами, если проект запускается через GitHub Actions;
 ● этот README.md.

Если в workflow ещё указано старое имя vpt_bot.py, замените его на vpt_bot_gemini_toggle.py во всех командах запуска.

Запуск вручную

Требуется Python 3. Скрипт использует стандартную библиотеку Python; отдельная установка Python-пакетов для основного скрипта не требуется.

Проверка расписания:

python3 vpt_bot_gemini_toggle.py today

python3 vpt_bot_gemini_toggle.py tomorrow

python3 vpt_bot_gemini_toggle.py week

python3 vpt_bot_gemini_toggle.py lastweek

Запуск Telegram-бота в режиме long polling:

python3 vpt_bot_gemini_toggle.py poll

Для запуска задайте переменные окружения TG_TOKEN и при необходимости TG_CHAT_ID, TG_PASSWORD, GEMINI_API_KEY.

Пример для Linux/macOS:

export TG_TOKEN=“токен_от_BotFather”

export TG_CHAT_ID=“ваш_telegram_id”

export GEMINI_API_KEY=“ваш_gemini_api_key”

python3 vpt_bot_gemini_toggle.py poll

Не публикуйте значения секретов и не сохраняйте их в репозитории.

Источник расписания

Расписание загружается из официального облака ВПТ, папка «2 КОРПУС РАСПИСАНИЕ».

Бот находит файл нужной даты, разбирает Excel-таблицу, извлекает блок группы РКЛ-3 и формирует сообщение с парами, преподавателями, кабинетами и временем звонков. Если файл на нужную дату ещё не опубликован, бот сообщает об этом, а не придумывает расписание.

Состояние и безопасность

 ● state.json содержит пользовательское состояние, включая контекст Gemini и сведения об отслеживаемых посылках.
 ● Не добавляйте токены и API-ключи в Git.
 ● Для публичного репозитория используйте только GitHub Secrets для секретных значений.
 ● При переносе бота на другой сервер перенесите state.json, если нужно сохранить накопленные данные.

Если что-то не работает

 ● Бот не отвечает: проверьте TG_TOKEN, доступность Telegram API и то, что запущен процесс poll или соответствующий workflow.● Gemini не отвечает: проверьте наличие GEMINI_API_KEY, корректность передачи секрета в окружение и доступность выбранной модели.
 ● Бот пишет, что ИИ не настроен: проверьте, что секрет называется точно GEMINI_API_KEY и передаётся в шаг запуска.
 ● Расписание не найдено: возможно, техникум ещё не опубликовал файл на нужную дату.
 ● GitHub Actions завершился с ошибкой: откройте вкладку Actions в репозитории и изучите журнал запуска.
 ● После обновления бот запускается старым файлом: проверьте имя Python-файла в workflow — должно быть vpt_bot_gemini_toggle.py.
