# Telegram-бот с Google Gemini

README для настройки проекта Telegram-бота, который отвечает пользователям с помощью Google Gemini.

## Что понадобится

- Python 3.10 или новее.
- Токен Telegram-бота, созданного через [@BotFather](https://t.me/BotFather).
- API-ключ Google Gemini из [Google AI Studio](https://aistudio.google.com/apikey).

## Подготовка

1. Склонируйте репозиторий или скачайте файлы проекта.
2. Установите зависимости, указанные в `requirements.txt`:

   ```bash
   pip install -r requirements.txt
   ```

3. Создайте файл `.env` в корневой папке проекта.
4. Добавьте в `.env` переменные окружения:

   ```env
   TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
   GEMINI_API_KEY=ваш_ключ_Gemini
   ```

5. Запустите файл приложения командой, предусмотренной проектом (например, `python main.py`).

## Важные правила безопасности

- Не публикуйте `.env` и никогда не отправляйте токены или API-ключи в чаты, GitHub и скриншоты.
- Добавьте `.env` в `.gitignore`.
- Если ключ случайно попал в открытый доступ, отзовите его и создайте новый.
- Не вставляйте секретные ключи непосредственно в исходный код.

## Настройка

Названия моделей Gemini, используемые методы SDK и команды запуска зависят от реализации проекта. Проверьте их в исходном коде и в актуальной документации Google Gemini API.

Документация: https://ai.google.dev/gemini-api/docs
