# Telegram-бот ВПТ

Бот-помощник ГБПОУ «Волжский политехнический техникум» (корпус №2, группа РКЛ-3).

## Что осталось в боте

- Расписание на сегодня, завтра, неделю и прошлую неделю из облака техникума.
- Автоотправка расписания и уведомление о появлении нового расписания.
- ИИ-ассистент Google Gemini с контекстом диалога (`/ai`, выход — `/cancel` или кнопка «❌ Отмена»).
- Отслеживание посылок Яндекс Доставки.
- Домашние задания: добавить текст или фото, посмотреть список и удалить запись.
- Новости мира, России и технологий — кнопка «📰 Новости», команда `/новости` или `/7`.
- Настройки, избранное, статистика, защита паролем и очистка временного кеша.

Музыкальный раздел и зависимость от Яндекс Музыки убраны из пользовательского меню. Файл `music_cache.json` для работы бота больше не нужен.

## Новости и скорость

Новости загружаются в фоновом потоке, поэтому бот не блокирует приём других команд. RSS-ленты мира, России и технологий запрашиваются параллельно; успешные ответы кешируются на 15 минут. Тайм-аут одной RSS-ленты — 7 секунд.

Обычные запросы к Telegram API имеют тайм-аут 12 секунд, а long polling — 30 секунд, чтобы не обрывать ожидание обновлений. При запуске командой `python bot.py poll` бот получает новые сообщения практически сразу после их отправки в Telegram.

**Важно:** GitHub Actions не является постоянно работающим сервером. Если запускать бота только периодическими workflow, ответы будут зависеть от интервала запусков и очередей GitHub. Для быстрых ответов держи `poll` постоянно запущенным на VPS/сервере или другом постоянно работающем хостинге.

## Запуск локально или на VPS

Нужен Python 3.10+ (сторонние пакеты не требуются).

Linux/macOS:

```bash
export TG_TOKEN="токен_от_BotFather"
export TG_CHAT_ID="твой_telegram_id"
export GEMINI_API_KEY="ключ_Gemini" # необязательно, только для ИИ
python3 bot.py poll
```

Windows PowerShell:

```powershell
$env:TG_TOKEN="токен_от_BotFather"
$env:TG_CHAT_ID="твой_telegram_id"
$env:GEMINI_API_KEY="ключ_Gemini"
python bot.py poll
```

Для полного фонового обслуживания (расписание, посылки и автоотправка) используй:

```bash
python bot.py run
```

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `TG_TOKEN` | Обязательный токен Telegram-бота от @BotFather |
| `TG_CHAT_ID` | ID чата администратора |
| `GEMINI_API_KEY` | Ключ Google AI Studio, если нужен ИИ |
| `TG_PASSWORD` | Необязательный пароль доступа |
| `ADMIN_CHAT_ID` | Необязательный отдельный ID администратора |

Не добавляй реальные токены и пароли в GitHub. Храни их в переменных окружения или GitHub Secrets.

## GitHub

1. Создай приватный репозиторий и загрузи файлы проекта, включая скрытую папку `.github`.
2. В `Settings → Secrets and variables → Actions` добавь `TG_TOKEN`, `TG_CHAT_ID` и при необходимости `GEMINI_API_KEY`, `TG_PASSWORD`.
3. Workflow `Проверка проекта` автоматически проверяет синтаксис и запускает тесты при push и pull request.
4. Для постоянной работы запусти `python bot.py run` на VPS/сервере. CI workflow сам по себе бота не запускает.

## Проверка

```bash
python -m py_compile bot.py
python -m unittest discover -s tests -v
```

Тесты не обращаются к Telegram, Gemini, облаку расписания или сервису доставки.

## Данные и безопасность

`state.json` создаётся автоматически и содержит настройки, историю ИИ, задания, трек-номера и кеш расписания. Не публикуй его в открытом репозитории: используй приватный репозиторий и резервные копии. Если Telegram-ботом пользуются другие люди, включи `TG_PASSWORD`.
