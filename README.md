# VPT Bot — РКЛ-3

Telegram-бот для группы РКЛ-3 Волжского политехнического техникума.

## Возможности
- Расписание РКЛ-3: сегодня, завтра, неделя и обновление.
- Локальный кэш расписания: кнопки читают базу данных, а сайт опрашивается в фоне.
- Общение между зарегистрированными пользователями: поиск по @username, подтверждение отправки, блокировка и отключение входящих сообщений.
- Отслеживание посылок по трек-номеру через Parcelle API, сохранение треков и фоновое обновление.
- Профиль и настройки приватности.

## Запуск на Windows 10/11
1. Установить Python 3.12 или новее.
2. Распаковать архив и открыть папку проекта в терминале.
3. Создать виртуальное окружение:
   `py -3.12 -m venv .venv`
4. Активировать:
   PowerShell: `.venv\\Scripts\\Activate.ps1`
   CMD: `.venv\\Scripts\\activate.bat`
5. Установить зависимости:
   `python -m pip install -r requirements.txt`
6. Скопировать `.env.example` в `.env` и указать `BOT_TOKEN`.
7. Запустить:
   `python -m app`

## Настройка отслеживания
Для реального поиска посылок нужен API-ключ Parcelle. Получить его можно через форму на странице разработчиков:
https://parcelle.ru/dev/
Добавить ключ в `PARCELLE_API_KEY`. Бот не выдумывает местоположение или сроки доставки: показывает только то, что вернул перевозчик/API.

## Расписание
По умолчанию бот ищет ссылку на расписание на официальной странице студентов ВПТ. Если ссылка на расписание не определяется автоматически или сайт публикует файл нестандартного формата, укажите прямую ссылку в `SCHEDULE_URL`.
Парсер рассчитан на HTML-таблицы. Если официальный сайт отдаёт расписание PDF/XLSX или требует авторизацию, потребуется отдельный адаптер под фактический файл/страницу. До успешного получения данных бот честно сообщает, что расписание временно недоступно, и не подставляет выдуманные пары.

## Общение
Пользователь должен хотя бы один раз открыть бота и нажать `/start`, чтобы его можно было найти и чтобы Telegram разрешил боту доставлять ему сообщения. Получатель может отключить входящие сообщения или заблокировать отправителя.

## Важно
