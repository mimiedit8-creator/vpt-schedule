# Бот расписания ВПТ (корпус №2, группа РКЛ-3)

Автоматически находит расписание группы **РКЛ-3** в официальном облаке
ГБПОУ «Волжский политехнический техникум» и присылает его в Telegram
каждый день в **20:00 по Москве**.

- Источник: [облако техникума](https://nextcloud.volpt.ru/index.php/s/bsycQtwSRF93676?path=%2F2%20%D0%9A%D0%9E%D0%A0%D0%9F%D0%A3%D0%A1%20%D0%A0%D0%90%D0%A1%D0%9F%D0%98%D0%A1%D0%90%D0%9D%D0%98%D0%95) (папка «2 КОРПУС РАСПИСАНИЕ», файл на каждый день)
- Скрипт: `vpt_bot.py` — только стандартная библиотека Python 3, без зависимостей
- Команды бота: `/1` (сегодня), `/2` (завтра), `/3` (посылка Яндекс Доставки), `/4` (прошлая неделя), `/today`, `/tomorrow`, `/week`, `/help` — при `/start` и `/help` внизу появляются кнопки
- `/start` всегда присылает расписание на сегодня
- **Пароль**: если задан секрет `TG_PASSWORD`, новый пользователь должен ввести пароль, чтобы пользоваться ботом (владелец с `TG_CHAT_ID` проходит всегда; принятые пароли запоминаются в state.json)
- **Посылки**: `/3` → бот просит трек-номер → показывает, где посылка; дальше проверяет её каждые 5 часов и присылает уведомление при движении
- **Кеш расписания**: команды `/1` `/2` `/start` отвечают из кеша (TTL 10 минут) — без ожидания облака; фоновые задачи обновляют кеш каждые ~30 минут. Если облако недоступно — приходят последние сохранённые данные с пометкой ⚠️
- **Скорость ответов**: раннер GitHub «слушает» Telegram по 40 минут каждый час (long polling) — команды обрабатываются за секунды, а не раз в час; уложились в бесплатный лимит приватного репозитория
- С 13:00 до 22:30 по Москве бот каждые ~30 минут проверяет, не опубликовано ли расписание на завтра, и присылает его сразу после публикации (не дожидаясь 20:00)
- Если расписание на завтра ещё не опубликовано к 20:00 — придёт сообщение об этом (без выдуманных пар)
- Если файл изменится после отправки — следующая отправка пометит сообщение «⚠️ изменено»
- Защита от повторной отправки одинаковых сообщений (state.json)

## Шаг 1. Создать бота в Telegram (2 минуты)

1. Откройте в Telegram [@BotFather](https://t.me/BotFather)
2. Отправьте `/newbot`
3. Введите имя бота (например, `Расписание ВПТ РКЛ-3`)
4. Введите username бота (например, `vpt_rkl3_bot` — должен заканчиваться на `bot`)
5. BotFather пришлёт **токен** вида `1234567890:AAHdqT...` — он понадобится на шаге 3
6. Найдите своего бота по username в поиске Telegram и нажмите **Start** (отправьте `/start`)

## Шаг 2. Узнать свой Telegram ID

1. Откройте в Telegram [@userinfobot](https://t.me/userinfobot)
2. Отправьте ему любое сообщение
3. Он пришлёт ваш числовой **Id** (например, `123456789`) — он нужен на шаге 3

## Шаг 3. Создать репозиторий GitHub и добавить секреты

1. Зарегистрируйтесь на [github.com](https://github.com) (если аккаунта нет)
2. Создайте новый репозиторий: кнопка **New repository** → имя, например `vpt-schedule` → **Create repository**
3. Загрузите в репозиторий файлы из этой папки:
   - на странице пустого репозитория выберите **uploading an existing file**,
   - перетащите `vpt_bot.py`, `README.md` и папку `.github` (или загрузите файлы по одному),
   - нажмите **Commit changes**
4. Добавьте секреты: в репозитории **Settings → Secrets and variables → Actions → New repository secret**:
   - имя `TG_TOKEN`, значение — токен из шага 1
   - имя `TG_CHAT_ID`, значение — ваш ID из шага 2
   - имя `TG_PASSWORD`, значение — пароль для входа в бота (по желанию: пусто = без пароля)
5. Если репозиторий приватный: **Settings → Actions → General → Workflow permissions** → выберите **Read and write permissions** (нужно для сохранения state.json)

Всё. Каждый день в 20:00 по Москве бот будет присылать расписание на завтра.
Первую отправку можно запустить вручную: вкладка **Actions** → выберите workflow
«ВПТ бот расписания» → **Run workflow** → `send` → **Run workflow**.

## Проверка вручную

```bash
python3 vpt_bot.py today      # расписание на сегодня
python3 vpt_bot.py tomorrow   # расписание на завтра
python3 vpt_bot.py week       # неделя
python3 vpt_bot.py send tomorrow --force   # отправить в Telegram сейчас
python3 vpt_bot.py poll                        # живой бот (команды) — для запуска на своём ПК
```

## Как это работает

1. Скрипт читает папку «2 КОРПУС РАСПИСАНИЕ» в облаке техникума (Nextcloud WebDAV)
2. Находит файл с датой завтрашнего дня (имена вида `17.11.2026 вторник 2 НЕДЕЛЯ.xlsx`)
3. Скачивает и разбирает Excel-файл, находит блок группы `1-26 РКЛ-3`
4. Формирует сообщение (пары, время по официальному расписанию звонков ВПТ, преподаватели, кабинеты)
5. Отправляет в Telegram через Bot API

Расписание звонков (из официального файла техникума):

| Пара | Пн–Пт | Суббота |
|---|---|---|
| 1 | 08:30–10:00 | 08:30–10:00 |
| 2 | 10:10–11:40 | 10:10–11:40 |
| 3 | 12:10–13:40 | 11:50–13:20 |
| 4 | 13:50–15:20 | 13:30–15:00 |
| 5 | 15:30–17:00 | 15:10–16:40 |
| 6 | 17:10–18:40 | 16:50–18:20 |

## Стоимость

Бесплатно: Telegram Bot API и GitHub Actions (для публичных репозиториев лимит минут не ограничен; для приватных — 2000 мин/мес, боту нужно ~40 мин/мес).

## Если что-то не работает

- **Actions не запускаются по расписанию** — GitHub может задерживать cron на несколько минут, это нормально
- **«расписание пока не опубликовано»** — техникум ещё не выложил файл на завтра; обычно выкладывают за день
- **Ошибки в Actions** — смотрите логи во вкладке Actions
